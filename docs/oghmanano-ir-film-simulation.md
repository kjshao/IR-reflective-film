# OghmaNano 红外反射膜仿真实操

## 1. 目标与必须先澄清的边界

目标为：

- 400–700 nm：高透射；
- 700–1300 nm：高反射。

这两个波段在 700 nm 共用同一个端点，但同一波长不可能同时高透和高反。实际规格必须给出过渡带，例如：

- 400–680 nm：平均透射率尽量高；
- 680–800 nm：允许从透射带过渡到反射带；
- 800–1300 nm：平均反射率尽量高。

还需要给出量化门槛，例如 `Tavg(400–680 nm) ≥ 75%`、`Ravg(800–1300 nm) ≥ 80%`，以及入射角、偏振、基板和是否包含基板背面。没有这些条件，“实现透射/反射”无法判定是否合格。

OghmaNano 的经典传输矩阵法（TMM）适合均匀平面多层膜，可计算反射率、透射率、吸收和膜内光场。其当前文档将该求解器限定为法向入射，因此 OghmaNano 用于正入射设计验证；0–60° 的 s/p 偏振和角度色偏需用本仓库脚本或其他斜入射 TMM 软件补算。

## 2. 推荐起始膜系

先使用氧化物/金属/氧化物/金属/氧化物（OMOMO）结构：

```text
空气 | ITO 35 nm | Ag 12 nm | ITO 85 nm | Ag 12 nm | ITO 35 nm | 玻璃 0.7 mm | 空气
```

在本仓库的代表性色散模型下，该结构的计算结果为：

| 入射角 | 400–700 nm 平均 T | 400–700 nm 最低 T | 800–1300 nm 平均 R | 800–1300 nm 最低 R | T=50% 截止边 |
|---:|---:|---:|---:|---:|---:|
| 0° | 78.0% | 53.0% | 82.7% | 58.6% | 706 nm |
| 30° | 76.6% | 48.3% | 83.5% | 62.2% | 694 nm |
| 45° | 73.6% | 42.2% | 84.4% | 66.3% | 678 nm |
| 60° | 65.5% | 32.9% | 85.5% | 72.5% | 650 nm |

这些数值只是仿真起点，不是材料保证值。Ag 的连续成膜状态和 ITO 的载流子浓度会显著改变结果；最终必须导入本机工艺制得薄膜的椭偏 `n(λ), k(λ)`。

### 为什么不直接使用简单全介质啁啾堆

三段 TiO₂/SiO₂ 四分之一波堆可以得到约 99.8% 的 800–1300 nm 平均反射率，但本次实际计算得到：

- 400–700 nm 平均透射率仅约 72%；
- 可见区最低透射率约 0.1%。

原因是宽带啁啾堆的高阶反射带进入可见区。它不能仅靠增加周期数或调整中心波长解决，必须采用专门的谐波抑制层胞和多目标薄膜优化。因此，不应把简单四分之一波啁啾堆直接作为满足本规格的设计。

## 3. 在 OghmaNano 中建立仿真

### 3.1 新建工程

1. 打开 `File` 功能区中的 `New simulation`；
2. 双击 `Optical filter` 示例；
3. 将工程保存到新目录；
4. 不使用光伏器件模板，避免无关的电学层和求解设置。

### 3.2 设置波长网格

打开 `Optical` → `Optical mesh editor`：

- start：350 nm；
- stop：1500 nm；
- wavelength points：至少 576 个，约 2 nm/点；
- 点击 `Rebuild`。

默认的稀疏波长网格会漏掉窄反射峰和截止边，不能用于滤光膜判断。

### 3.3 导入材料光学常数

打开 `Databases` → `Materials Database`，分别检查或添加 ITO、Ag 和玻璃材料。每种材料必须覆盖至少 350–1500 nm。

OghmaNano 原生材料文件使用：

| 文件 | 两列数据 | 单位 |
|---|---|---|
| `n.csv` | wavelength, n | m，无量纲 |
| `alpha.csv` | wavelength, α | m，m⁻¹ |

若原始数据为消光系数 `k`，按下式转换：

\[
\alpha(\lambda)=\frac{4\pi k(\lambda)}{\lambda}
\]

其中波长必须使用米。本仓库运行脚本后会生成可导入的示例：

```text
sim/out/oghma_materials/<material>/n.csv
sim/out/oghma_materials/<material>/alpha.csv
```

这些文件来自解析近似模型，仅用于复现和界面练习；正式结果应换成实测材料数据。

### 3.4 建立层结构

打开 `Device structure` → `Layer editor`，从入射面开始依次输入：

| layer | material | `dy`（m） | Solve optical problem |
|---:|---|---:|---|
| 0 | ITO | `3.5e-8` | `Yes – n/k` |
| 1 | Ag | `1.2e-8` | `Yes – n/k` |
| 2 | ITO | `8.5e-8` | `Yes – n/k` |
| 3 | Ag | `1.2e-8` | `Yes – n/k` |
| 4 | ITO | `3.5e-8` | `Yes – n/k` |
| 5 | Glass | `7.0e-4` | `Yes – k`（非相干） |

薄膜层必须保留相位信息；毫米级玻璃基板应设为非相干，否则会产生现实分光仪无法分辨的密集干涉条纹。若直接输入厚基板导致显示或数值尺度不便，可在层编辑器中设置较小的仿真厚度，再通过 Transfer Matrix 窗口的 `Optical Thickness` 设置 0.7 mm 等效光学厚度。

### 3.5 光源与求解器

1. `Optical` → `Light sources`；
2. 选择覆盖 350–1500 nm 的连续光谱，例如 AM1.5G 或自定义平坦光谱；
3. `Illuminate from` 选择 `top (y0)`；
4. `Optical` → `Transfer matrix`；
5. 模式选择 `Transfer matrix`，点击运行。

光源强度会影响绝对光子密度，但反射率和透射率是归一化比例。不要用光源编辑器中的吸收型 filter 代替待设计膜层。

## 4. 读取并检查结果

在 `Output` → `optical_output` 中读取：

- `reflect.csv`：波长与反射；
- `transmit.csv`：波长与透射；
- `optical_snapshots`：各波长处的电场和吸收空间分布。

逐波长检查能量守恒：

\[
R(\lambda)+T(\lambda)+A(\lambda)=1
\]

对于 OMOMO，吸收主要发生在 Ag，其次是近红外自由载流子吸收较强的 ITO。若 OghmaNano 与本仓库正入射参考曲线相差超过约 1%，应依次检查：

1. 材料 `n, k` 数据是否完全相同；
2. 波长和吸收系数是否误用了 nm、cm⁻¹；
3. 层序是否从入射侧开始；
4. 玻璃是否按非相干层处理；
5. 是否包含基板背面空气界面；
6. 波长网格是否足够细。

## 5. 厚度扫描

打开 `Automation` → `Parameter Scan`，使用 `epitaxy.layerN.dy` 扫描膜厚。推荐两阶段扫描：

1. Ag：8–16 nm，步长 1 nm；
2. ITO 外层：20–60 nm，步长 5 nm；中间层：60–110 nm，步长 5 nm。

对称层用 `duplicate` 联动：

- layer 3 的厚度复制 layer 1；
- layer 4 的厚度复制 layer 0。

每次扫描后计算而不只目测：

- `Tavg(400–680 nm)`；
- `Tmin(400–680 nm)`；
- `Ravg(800–1300 nm)`；
- `Rmin(800–1300 nm)`；
- T=50% 截止边；
- 可见吸收；
- 厚度 ±1 nm 或 ±2 nm 的最坏情况。

OghmaNano 的参数扫描适合少量变量和容差分析，不等同于专业镀膜软件的 Needle 多目标膜系合成。

## 6. 本仓库的复现方法

无需安装第三方 Python 包：

```bash
python3 sim/design.py
```

脚本会：

- 用裸玻璃、四分之一波减反层和六周期 Bragg 镜进行解析自检；
- 计算 0°、30°、45°、60° 的非偏振 R/T；
- 将厚玻璃及其背面按非相干方式处理；
- 输出 OMO、OMOMO 和不合格全介质基线的参考光谱；
- 生成 OghmaNano 示例材料文件。

输出位于：

```text
sim/out/route_a1_omo.csv
sim/out/route_a2_omomo.csv
sim/out/route_b_dielectric.csv
sim/out/oghma_materials/
```

脚本的斜入射计算用于补充 OghmaNano 正入射 TMM 的能力边界。正式定型前还应加入实测色散、膜厚统计分布、界面粗糙度及 Ag 不连续成膜造成的附加损耗。
